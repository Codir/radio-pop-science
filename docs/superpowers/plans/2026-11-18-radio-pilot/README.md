## `facts/` — звіти про рушій

Десять звітів, написаних 18.11.2026 з дерева на коміті `63fd42c` (одразу після злиття з `upstream`).
Кожен називає файли й рядки, з яких узято факт. Мова звітів — англійська, цитати з рушія — дослівні.

| Звіт | Про що |
|---|---|
| `volume-anatomy.md` | з чого складається том формату «шлях», `volume.json`, збудовані й заплановані глави, бібліотека |
| `content-pipeline.md` | сценарії глав у markdown, перевірки й бюджети, експорт, документи тому |
| `chapter-api.md` | договір глави з рушієм: сцена, кроки, керування, камера, рендерер, час і випадковість |
| `reference-chapters.md` | як збудовано глави `circuit`: файли, спільний світ, тести, ворота |
| `kit-fx-ui3d.md` | готові деталі: моделі, ефекти, текст, кольори, звук, бюджети кадру |
| `sim-worker-lint.md` | правила для моделей, лінт, TypeScript, фоновий потік, тести |
| `spec-requirements.md` | вимоги проєкту для черг 1–3 з номерами рядків |
| `upstream-delta.md` | що змінило злиття з `upstream` і які твердження проєкту застаріли |
| `baseline-checks.md` | середовище на цій машині й базова лінія всіх перевірок |
| `site-profile-probe.md` | перевірений рецепт сайту з одним томом і чернетка публікації |

Шляхи виду `/tmp/claude-…/scratchpad/…` у звітах — робочі каталоги тієї сесії; їх уже немає. Усе потрібне
з них перенесено сюди, у `prototypes/`.

Звіти — знімок на одну дату. Після кожного нового злиття з `upstream` факт зі звіту перевіряють у коді,
перш ніж на нього спертися.

## `prototypes/` — перевірені заготовки

| Що | Звідки й навіщо |
|---|---|
| `site/build.mjs`, `site/smoke.mjs` | профіль сайту: копія `app/` з одним томом, збірка й перевірка в браузері. Пройшов для `radio` (чернетка без глав) і для `circuit`. З них виростає `tools/site/` (завдання A7). |
| `qa-shims/montage`, `identify`, `mogrify` | заміна трьох команд ImageMagick на Pillow — стільки, скільки потрібно `tools/qa/sheet.sh`. З ними `chapter-check` тут проходить. |
| `model/slope_scan.py` | перебір параметрів детектора на схилі; дав `r = 0,20`, `θ = 82°` (відхилення від прямої 6,2 %). |
| `model/chain.py`, `run3.py`, `yardgeo.py`, `site_run2.py` | проби автора розділу про модель (numpy): увесь ланцюг за договором, крива «чистота проти рівня», геометрія подвір'я й рівні на зупинках. З них узято пороги тестів B4, B6 і B9. Це докази, а не еталон: еталон пише окремий агент із договору. |
