## 1. File-by-file template of a chapter

### 1.1 Pipeline: script → JSON → step modules

| Stage | File | What it carries |
|---|---|---|
| script (contract) | `docs/volumes/circuit/chapters/<id>.md` (prologue 183, wire 192, charge 235 lines) | `# <id> — <Title?>`; `## Питання з життя`; `## Що ми вже знаємо`; `## Кроки` with `### N. \`<step-id>\` — <Title>`; per step fields `- **Думка:**`, `**Текст:**`, `**Дія:**`, `**Висновок:**`, `**Ціль:**`, `**Підказки:**` (≤ 2), `**Підписи:**`, `**Нові терміни:**`, `**Докладніше:**`, optional `**Згадати:**`, `**Бачимо:**`; `## Нитка глави`; `## Що ми тепер знаємо` (3 numbered lines); `## Місток`; trailing `<!-- Примітки щодо фактів … -->` |
| register | `docs/volumes/circuit/chapters/_terms.md` | tables «Терміни шляху» (`Термін \| Форми (regex) \| Крок \| Тип шлях/практикум \| Картка`), «Слова, які читач уже має», «Слова лише для «Докладніше»», «Чого на шляху немає» |
| export (generated) | `docs/volumes/circuit/chapters/_export/<id>.json` | `schemaVersion: 1, format: "path", volume, id, title, layer, group, order, parent, floor, axisValue, minutes, hook, know, thread, now[3], bridge, labels[], next{id,title}, steps[]{id,title,idea,text[],action,takeaway,terms[],more[],recall[],hints[],captions[],goal,see}, glossary[]` |
| runtime (generated) | `C/content/generated/<id>.json` | `volume, id, title, group, path{layer,hook,know,now[],bridge,next{id,title},minutes}, steps[]{id,title,panel[],terms[],path{idea,action,takeaway,more[],marks[],recall[],hints[],captions[]},labels[]}, glossary[]` — **no `goal`, no `see`** (builder guidance stays in `_export`) |
| manifest (generated) | `C/content/generated/<id>.manifest.json` | `volume,id,title,subtitle,axisLabel,axisValue,group,parent,order,format:"path",layer,minutes,steps[]{id,title,blurb}` (`blurb` = the step's «Думка») |
| chapter manifest | `chapters/<id>/index.ts` | `defineChapter({ id, order: meta.order, group, ...manifestText(meta), axisValue: meta.axisValue, theme, load: () => import('./scene') })` |
| content | `chapters/<id>/content.ts` | `export default defineContent(raw)`; discovered by glob `../volumes/*/chapters/*/content.ts` (`app/src/content/loader.ts:9`) |
| typed step ids | `chapters/<id>/chapter.ts` | `export const STEP_IDS = [...] as const` — must equal the generated step order (pinned by `__tests__/manifest.test.ts`) |
| scene | `chapters/<id>/scene.ts` | `FACTORIES: Record<StepId, StepFactory>` → `world.define({<stepId>: spec})` + `ui.define({<stepId>: ui})` |
| step module | `chapters/<id>/steps/NN-<step-id>.ts` | one exported factory per step |

Field mapping: «Підписи» → `labels[]` (order kept) + `path.captions[]` `{text}` / `{text, until:'takeaway'}` /
`{text, at:'takeaway'}` (syntax `«A»` · `«A» → «B»` · `→ «B»`, `tools/content/path_format.py:31-33`); «Ціль» →
implemented by hand as `StepUiSpec.goal: When` (`app/src/hud/step-ui-types.ts:270-275`); «Підказки» → `path.hints`
(shown after 15 s and 40 s, `tools/content/path_check.py:120-121`); «Згадати» → `path.recall[{target,title}]`;
«Нові терміни» → `terms[]` + `path.marks[{text,term}]`; «Бачимо» → `see` (export only). «Позначки» / «Чесно» are
**accepted and dropped** (`tools/content/path_format.py:26-28`).

Regeneration: `tools/content/regen.sh --volume <id>` = `build_index.py`, `build_glossary.py`, `export_content.py
--quiet`, `export_runtime.py`, then `doccheck.py … | tail -24` (`tools/content/regen.sh`). `INDEX.md` and
`GLOSSARY.md` of the volume are generated (`docs/volumes/circuit/INDEX.md:1`: «Generated by
tools/content/path_export.py … do not edit»).

Contract (`C/chapters/wire/chapter.ts:13-45`):

```ts
export const STEP_IDS = ['atoms', 'inside-atom', 'outer', 'shared', 'restless', 'plastic'] as const;
export type StepId = (typeof STEP_IDS)[number];
export interface Chapter {
  ctx: ChapterContext;
  ui: StepUiApi<StepId>;
  world: WireWorld;
  reached(step: StepId): boolean;   // goal reached this session → takeaway, captions «→ X»
  reach(step: StepId): void;
}
export interface StepModule {
  spec: StepSpec;                   // camera, params, env, post
  ui: StepUiSpec;                   // controls, callouts, goal
  enter?(info: StepInfo): void;     // also on deep links: honour info.instant
  leave?(): void;
  update?(dt: number, t: number): void;
}
export type StepFactory = (chapter: Chapter) => StepModule;
export const sessionGoals = { has: (s: StepId): boolean => …, add: (s: StepId): void => … };
```

`WireWorld` (`C/chapters/wire/world.ts:18-31`): `world: CircuitWorld; copper: Copper; between(a, b, t): Shot;
toWorld(local, out?): Vector3; state(floor: 'rows'|'atom', lamp: 0|1, camera: CopperShot|string): StepSpec;
go(camera, opts?): void; name(name, make: () => Shot): void; update(dt, t): void`. `state()` returns
`{ camera: nameOf(camera), params: { deep: DEEP[floor], closed: lamp, lens: 1 } }` (`world.ts:64-67`).

Scene skeleton (`C/chapters/wire/scene.ts:34-106`), in order:

1. `const world = createWireWorld(ctx)`; `const ui = stepUi(ctx) as StepUiApi<StepId>`.
2. `const ladder = floorLadder(ctx, { floor: () => (world.world.deep > 0.01 ? world.world.floorId : null) })`.
3. `const before = ctx.store.get(); let from = before.volumeId === ctx.manifest.volume && before.chapterId !== ctx.manifest.id ? before.chapterId : null;` — the neighbour the reader comes from (`scene.ts:42-44`).
4. `const steps = Object.fromEntries(STEP_IDS.map((id) => [id, FACTORIES[id](chapter)]))`.
5. `world.world.define(… { ...m.spec, enter: m.enter?.bind(m), leave: m.leave?.bind(m) })`; `ui.define(… steps[id].ui)`.
6. `ctx.qa.expose('wire', () => ({ step, depth, deep, position, flying, lamp, reached }))`.
7. hooks: `enterStep(id, info)` → `world.world.enterStep(id, info)` first; then `flyIn` (from the prologue) or `world.world.border.arrive(id, from, { then: () => steps[id].enter?.({ ...info, instant: false }) })`; `leaveChapter(to)` → `steps[current].leave?.(); leaving = true; return world.world.border.leave(to.chapterId)`; `update` → `if (!leaving) steps[current].update?.(dt, t); world.update(dt, t); ladder.update()`.

Step-module pattern (every `steps/NN-*.ts`): header doc comment naming the script step; constants with units;
`export const <camel>Step: StepFactory = ({ ctx, ui, world, reached, reach }) => { … return { spec, ui, enter, leave?, update } }`;
a `here()` guard (`ctx.stage.current === '<id>'`); input through `ctx.input.register(mesh, { cursor, enabled, hover, click, dragStart, drag, dragEnd, tooltip })`;
QA hooks `ctx.qa.probe('<name>', () => Vector3)` and `ctx.qa.expose('<step>', () => state)`; `spec:
{ ...world.state(floor, lamp, shot), duration, ease?, cameraMove: { duration } }`; `ui: { reset?, controls: [...], goal:
() => reached('<id>'), callouts: [{ anchor, text: caption('<id>', i), side, visible }] }`; `enter` re-derives the whole
state (deep link = the frame a reader arrives at); goal → `reach('<id>')`.

### 1.4 Naming conventions (verified in code)

- Directory = chapter id = `defineChapter({ id })`; step file `steps/NN-<step-id>.ts`, export `<camelCaseId>Step`.
- Stage params shared by the volume are named once in `shared/world/params.ts` (`WorldParam`).
- Shots: shared ones by bare name (`stand`, `lens`, `handover`, `away`), copper ones prefixed `copper-<name>`, chapter-own ones prefixed `<chapter>-<name>` (`charge-table`, `charge-crumbs`) or local names (`one-wide`, `lens-start`).
- QA: `ctx.qa.expose('<chapter>', …)` for the scene, `ctx.qa.expose('<step>', …)` per step (`'charge-step'` where the step id equals the chapter id); probes kebab-case nouns (`atom-hero`, `spare-left`).
- HUD control ids kebab-case (`depth`, `apart`, `add-atoms`, `riddle-time`) → `__ui.locate('ctl-<id>')`.
- All Ukrainian reader text comes from generated JSON via `caption(step, i)`; exception found: `board: { title: 'Мапа тому', … }` typed in code (`C/chapters/prologue/steps/map.ts:29`).
- Volume alias: `@circuit/*` → `./src/volumes/circuit/*` (`app/tsconfig.json:22`; vite derives it from the directory name, `app/vite.config.ts:14-18`).
- Chunk names depend on file names: `volumes/<v>/chapters/<id>/scene.ts` → `assets/chapter-<v>-<id>-[hash].js`, `volumes/<v>/chapters.ts` → `assets/volume-<v>-[hash].js` (`app/vite.config.ts:63-69`).
- Lint for `src/volumes/*/chapters/**/*.ts` (`app/eslint.config.js:37-62`): only `@/engine/api` of the engine, no `gsap`, no `Date.now`, `performance.now`, `window.setTimeout`, `Math.random`; `local/chapter-boundary` allows the own chapter, `@/…`, and the own volume's `sim/**`, `content/**`, `shared/**` only (`app/eslint-rules/chapter-boundary.js:24`). These `no-restricted-properties` do **not** apply to `shared/**` (only `setInterval` is restricted for all `src/**/*.ts`).
- `ChapterContext` members used by the three chapters + `shared/world`: `ctx.stage.{setParam,current,define,scope,param}`, `ctx.qa.{probe,expose}`, `ctx.input.register`, `ctx.camera.{go,moving,camera,shots,target,hold}`, `ctx.root.add`, `ctx.post.apply`, `ctx.env.tune`, `ctx.manifest.{id,volume}`, `ctx.store.get`, `ctx.reducedMotion`, `ctx.viewport.height`, `ctx.random.fork`, `ctx.onDispose`, `ctx.nav.volume`, `ctx.device.formFactor`.

### 3.5 Borders (`border.ts`)


- The border frame = stand shot, lens in its holder, lens window shut, nothing of a chapter's own on the table, switch
  and wire tint as `BORDERS` says (keyed by the **earlier** chapter of the pair). `prologue | wire` is the «away» frame.
- `leave(to)` walks there (flight up if below the stand; else `ctx.camera.go('stand', { duration: 2.4, ease: 'sine.inOut' })`) and returns the predicate «there» (`border.ts:166-175`).
- `arrive(id, from, opts)` snaps the step (entered instantly behind the cross-fade) onto the border frame, holds `HOLD` 0.5 s, then moves into the step's params/camera (or dives) and calls `then` so the chapter replays its own entry non-instantly; returns `false` for a deep link.
- `ORDER` duplicates the journey order of `volume.json` by hand.

## 7. Seamless volume obligations

Definition: `VolumeIdentity.seamless?: boolean` — «The chapters share one world and every border is the same frame …
a chapter change is a short plain cross-fade, never the scale-zoom. Default false.» (`app/src/engine/volume.ts:52-56`);
`docs/VOLUMES.md:196`.

Runtime conditions (`app/src/engine/runtime.ts`):

- `SEAMLESS_FADE = 0.3`, `LEAVE_MAX = 12`, `INSET_HOLD = 0.8` (`:43,45,47`).
- On a chapter change the runtime calls `out.hooks.leaveChapter?.({ volumeId, chapterId, stepId }) ?? null` (`:415`); `this.border = exit !== null`; a number = seconds, a function = predicate polled up to 12 s; skipped when `deterministic()` (`?freeze`).
- The cross-fade happens only if **all** hold: previous chapter exists, same volume, `this.border` (the hook returned non-null), `library.get(volume)?.seamless === true` (`:512-516`). Otherwise `MOTION.transition.duration` (1.35 s, `app/src/style/motion.ts:35`) zoom with chromatic aberration and `director.arrive(direction > 0 ? 1.9 : 0.55, …)`.
- Seamless swap: `next.director.followDrift(previous.director)`, `setInsets(framed, true)`, HUD keeps its chrome (`app/src/hud/shell.ts:153-154`), no whoosh (`app/src/audio/plugin.ts:49-50`), loading pill waits 3 s (`TransitionState.quiet`).

Hook signature (`app/src/engine/chapter.ts:141`):

```ts
leaveChapter?(to: { volumeId: string; chapterId: string; stepId: string }): number | (() => boolean) | null;
```

What `seamless: true` obliges **each chapter** to implement (as all nine `circuit` chapters do):

1. `leaveChapter(to)`: call the current step's `leave()`, set `leaving = true`, put chapter-own props/tools away, walk to the shared border frame, return seconds or a predicate; return `null` for a non-neighbour (jump across the map → platform zoom).
2. Remember the neighbour at creation: `ctx.store.get()` → `from`.
3. In `enterStep` when `info.from === null`: start on the border frame (`border.arrive`), hold 0.5 s, then replay the step's own entry non-instantly; a deep link does nothing.
4. First and last frames of the chapter are the border frame (tested: charge «the first frame is the stand shot», «the last frame is the first frame again»).
5. A volume-level border table (`BORDERS`, `ORDER`) and a regression: `volume-walk.mjs`.

A volume that does **not** set `seamless`: every chapter change is the platform's 1.35 s scale-zoom (direction from the
journey axis, `Library.zoomDirection`, `app/src/engine/library.ts:218-225`), HUD panels hide and show, whoosh sound;
`leaveChapter` is optional and, if returned non-null, only delays the swap; no border table needed. `volume-walk.mjs`
would then report every border as `the first frame differs from the last one` (it is «the regression test of a
`seamless` volume's borders», `docs/ARCHITECTURE.md:182-186`).
